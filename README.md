# Обход ДКС

Android-приложение для записи показаний на обходе ГПА.

## Что умеет

* **ГПА:** Валанжин 1–12, Сеноман 1–3. На главном экране видно время последней записи
  (зелёное — сегодня), метка **ОТКЛОНЕНИЕ** и число открытых замечаний.
* **Показания:**
  * пожарные баллоны №1–5: вводятся только цифры, запятая и минус (кнопка **±** меняет знак);
    запятая ставится автоматически после первой цифры.
    Если значение больше 2,8 или меньше −2,8, поле краснеет с надписью **ОТКЛОНЕНИЕ**;
  * МСК: уровень в маслобаке и перепад на фильтрах; для Валанжина также **утечки СГУ-1 и СГУ-2**;
  * двигатель: уровень в маслобаке; для Валанжина — давление до и после фильтров, **перепад считается автоматически**; у Сеномана блок давления на фильтрах не отображается;
  * **автосохранение**: значения сохраняются сами сразу после ввода и остаются в ячейках;
    ввод по одному ГПА в течение часа — одна запись обхода, позже — новая запись
    (прошлые показания видны серым). Кнопка «Новая запись» начинает запись вручную;
  * вкладка **История** со всеми прошлыми записями.
* **Ангар:** фото с камеры или из галереи (сколько угодно), подпись к каждому фото
  и общие примечания.
* **Замечания:** описание, фото, отметка «Устранено».
* **PDF-отчёты:** кнопка во вкладке «Замечания» формирует отчёт по конкретному ГПА,
  а кнопка на главном экране — общий отчёт по всем ГПА с группировкой по участкам.
  В отчёт входят открытые и устранённые замечания, пояснения, фотографии, дата формирования
  и сводка по статусам. Фотографии масштабируются компактно: на одной странице помещаются
  минимум два замечания с фото и пояснениями. PDF создаётся на устройстве; его можно сохранить
  или отправить через системное меню. В браузере используется меню «Поделиться» либо скачивание файла.

Все данные и фото хранятся на телефоне, интернет не нужен.

## Как установить

Каждый пуш собирается в GitHub Actions. Готовый `DksObhod.apk` лежит в
**Releases → «Последняя сборка»**. Скачайте его на телефон и установите
(может понадобиться разрешить установку из неизвестных источников).

Все сборки подписаны одним ключом (`app/keystore`), поэтому новая версия ставится
поверх старой и данные сохраняются.

## Сборка вручную

Откройте проект в Android Studio или выполните `./gradlew assembleRelease`.

## Версия для iPhone (веб)

`web/obhod.html` — та же программа одной веб-страницей: показания, ангар, замечания, фото.
Данные хранятся в браузере телефона (IndexedDB).
Офлайн-версия для GitHub Pages лежит в `docs/` (после правок `web/obhod.html` выполните
`python3 web/build_docs.py`). В Safari: «Поделиться → На экран „Домой“»,
и страница откроется как отдельное приложение. Готовый файл `DksObhod-iPhone.html` тоже лежит в Releases.

### Публикация GitHub Pages

Сайт https://ampkirill-bot.github.io/DNS-game/ публикуется из **корня** ветки
`claude/android-machinist-notes-app-6b6t37`. После завершения изменений веб-версии необходимо
скопировать актуальные `index.html` и `sw.js` в корень этой ветки. Изменения только в `docs/`
другой ветки не обновляют опубликованный сайт. Проверять нужно содержимое страницы по ссылке,
а не только успешное завершение публикации.
